Windows PC & laptop diagnostics

PC Health Check

See what is inside the computer, watch CPU and GPU temperatures live while a stress test runs, check battery wear and pull up recent crashes and hardware errors. Finish with a downloadable report.

Step 1 · Start the TECHM8 agent Not connected

Browsers are not allowed to read temperatures, battery wear or Windows error logs. A small read-only PowerShell script reads them and passes them to this page. It installs nothing, changes nothing and stops when its window is closed.

  1. Right-click the Start button and choose Terminal (Admin) or Windows PowerShell (Admin).
  2. Paste this command and press Enter:
irm https://www.techm8australia.com/tools/techm8-agent.ps1 | iex
  1. Leave the blue window open, then press
  2. If Chrome or Edge asks to let this site access apps on this device, choose Allow.

Prefer a file? Download techm8-agent.ps1, then right-click it and choose Run with PowerShell. For accurate CPU temperatures and fan speeds, also run LibreHardwareMonitor as administrator; the agent picks up its sensors automatically. Without the agent you can still run the stress test and see basic browser-level details.

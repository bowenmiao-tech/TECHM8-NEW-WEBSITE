PC Health Check

TECHM8 Diagnostics for Windows

Download TECHM8-Diagnostics.exe
  1. Open the downloaded file. If Windows shows “Windows protected your PC”, choose More info › Run anyway.
  2. Choose Yes when Windows asks to allow changes. The program needs administrator rights to read sensors and logs.
  3. For CPU temperatures, click Install CPU sensor driver at the top. It installs PawnIO, the signed open-source driver used by LibreHardwareMonitor, and offers to remove it again when you close the program.
  4. Open the Stress test tab, pick a duration and press Start. Save the report from the Report tab when you are done.

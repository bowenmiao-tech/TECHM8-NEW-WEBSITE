Windows keeps a few keys for itself: the Fn key never reaches a web page, Print Screen only registers on release, and Alt+Tab / Ctrl+Alt+Del cannot be blocked. A key with an orange outline registered twice for one press, which usually means a worn switch or a dirty contact.
